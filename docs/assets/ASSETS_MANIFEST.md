# GateXPay Assets — Developer Handoff

This directory contains production-ready image and media assets for GateXPay developer handoff.

> **Note**: In accordance with front-end best practices, **all UI icons have been excluded** (icons should be implemented using the `lucide-react` component library or inline SVGs). This directory contains strictly **content images, illustrations, device mockups, banners, portraits, and brand marks**.

---

## Directory Overview

```
assets/
├── services-listing/          # All 26 full-resolution service card illustrations
├── services-detail/           # Service detail page illustrations & architecture graphics
│   ├── payment-gateway/       # Payment gateway hero illustration & architecture diagram
│   ├── pan-card/              # PAN card hero illustration & document verification visual
│   ├── bill-payment/          # Bill payment hero illustration & payment device mockup
│   └── digital-marketing/     # Digital marketing hero illustration & platform tools visual
├── home-page/                 # Hero device mockups (MacBook, iPhone, iPad, Composite) & bento cards
├── contact-us-pop-up/         # Contact modal dialog (blur backdrop & clean card)
├── contact-us/                # Jaipur headquarters office photo
├── about-us/                  # Hero banner, founder portrait (Vansh Chaudhary), ecosystem & foundation cards, Jaipur map
├── blog-listing/              # Featured RBI licensing insight cover & 6 article card thumbnails
├── blog-detail/               # Long-form article hero banner & author avatars
└── common/                    # Official GateXPay logos (full mark, symbol, wordmark)
```
